# 🚗 Auto Gallery Showcase

A minimalist, high-performance bilingual (English / Turkmen) automotive web showcase designed for smooth user interaction and sleek media display.

![Auto Gallery Banner](https://auto-galery.netlify.app/img/camry-xv30.jpg)

## ✨ Key Features
- Bilingual Interface: Seamless instant switching between English (EN) and Turkmen (TM).
- Interactive Specs Modal: Detailed pop-ups with technical specifications (engine, transmission, drive type, color).
- 1:1 Aspect Ratio Grid: Uniform, responsive card layout tailored for all screen sizes.
- Direct Phone Contact Integration: Quick-action call links (+993 71 305949).

## 🛠️ Built With
- HTML5: Semantic document structure.
- CSS3: Custom CSS grid, modal overlay styles, dark/light contrast elements.
- JavaScript (Vanilla): Dynamic modal rendering and language toggle logic.
